# Vienna Christmas 2026 guide

Static Hebrew (RTL) trip guide. No build step.

- `index.html` content (sections: markets, food, bars, shopping, plan, checklist)
- `css/style.css` design tokens and styles (light/dark)
- `js/carousel.js` photo carousels, `js/checklist.js` saved checklist (localStorage)
- `img/` photos (Wikimedia Commons, free licenses; Google Maps place photos, personal use). Credits are listed at the bottom of the page.

Edit a file, commit, and GitHub Pages republishes in about a minute.
